# Dog Finder 🐶

## Description

Dog Finder is a JavaScript web application that allows users to search for dog images by breed using The Dog API. Users can also add their favorite dog images using a POST request.

---

## Features

- Search for dog breeds
- Display dog images
- Add favorite dogs
- Responsive layout
- Uses JavaScript modules
- Uses Fetch API
- Uses async/await

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Fetch API
- The Dog API

---

## API Used

https://thedogapi.com/

---

## How to Run

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension (if needed).
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Search for a breed and view dog images.
